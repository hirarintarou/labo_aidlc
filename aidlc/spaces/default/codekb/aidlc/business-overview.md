# ビジネス概要

## 対象プロダクト

本リポジトリ（CodeKB 識別子 `aidlc`）のプロダクト本体は、`app/` 配下の Python プロジェクト `screenshot-editor` である。FF14（ゲーム）のスクリーンショットを、ローカルかつ非破壊で加工する Windows デスクトップアプリケーション。

## ドメインと目的

- **ドメイン**: 個人向けの画像加工（スクリーンショット編集）。
- **目的**: 撮影したスクリーンショットを、明るさ・コントラスト・彩度などの調整、フィルタ／プリセット適用、トリミング・リサイズ、クレジット付与といった編集を通じて手軽に仕上げること。
- **設計原則**:
  - **ローカル完結**: ネットワーク送信を行わない（外部 API 呼び出しなし）。
  - **非破壊**: 元画像を上書きせず、別ファイルへアトミックに保存する。

## 主要機能

- 画像を開く（安全なデコード、画素数上限による保護）。
- 調整（明るさ／コントラスト／彩度／シャープ／ぼかし／ノイズ除去）をスライダーで編集。
- フィルタ／プリセット（`BUILTIN_PRESETS` の 8 種）を選択して適用。
- リアルタイムのプレビュー更新。
- 複数ファイルへの一括適用（バッチ処理）と結果集計。
- 非破壊保存（`save_nondestructive`、出力パス自動生成）。

## ワークフロー・ツールの位置づけ（プロダクトではない）

リポジトリには `.kiro/` と `aidlc/` のディレクトリが存在するが、これらは AI-DLC（AI-Driven Development Life Cycle）ワークフローの scaffolding・ワークスペース記録であり、**プロダクトの一部ではない**。開発プロセスのコンテキストとして扱い、プロダクトのビジネス機能とは区別する。

## 関連 intent

現行 intent `preview-changed-error`（画像を開いて調整・フィルタ・プリセットを選択するとコンソールにエラーが出る）は、この編集プレビュー経路の不具合に関するもの。根因の詳細は `code-quality-assessment.md` を参照。
