# ロールバック・ランブック — preview-changed-error（bugfix）

## 概要

ローカル完結アプリのため、ロールバック＝`main` 上での修正コミットの取り消し（または前リリースタグへの復帰）と、ローカル再インストール。元画像は非破壊で保護されており、ロールバックによるユーザーデータ喪失リスクはない。

## ロールバック手順

1. 問題を検知（起動不可、コンソールに新たなエラー、既存機能の退行など）。
2. 対象コミットを特定: `git log --oneline` で本 bugfix コミット（`fix(ui): 調整・プリセット操作時のコンソールエラーを解消`）を確認。
3. 取り消し（いずれか）:
   - 直近コミットを打ち消す新コミット: `git revert <commit>`（履歴を保持する非破壊的な戻し。推奨）。
   - 前リリースタグへ復帰: 対象タグをチェックアウトしてローカル再ビルド。
4. ローカル再検証: `QT_QPA_PLATFORM=offscreen python -m pytest -q` が green であることを確認。
5. アプリを再起動し、スモークテスト（画像を開く→調整/プリセット操作→コンソールにエラーが出ない）で復帰を確認。

## 注意

- `git reset --hard` / force push などの破壊的操作は行わない（`git revert` を用いる）。
- 元画像は上書きしない設計のため、ロールバックで画像データが失われることはない。

## エスカレーション

- 個人開発のため外部エスカレーション先はなし。判断は開発者本人が行う。
