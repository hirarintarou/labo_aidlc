# Accessibility Checklist — FF14 スクリーンショット加工ツール（mvp）

個人利用のWindowsデスクトップアプリ。網羅的なWCAG準拠監査は求めず、確定したNFR4（見やすさ・キーボード操作性）を担保する最低ラインをチェックリスト化する [NFR4]。

> 注: 完全なWCAG 2.1 AA準拠の確証には、支援技術（スクリーンリーダー等）での手動検証と専門家によるアクセシビリティレビューが必要です。本チェックリストはmvpに比例した最低ラインを対象とします。

## チェック項目

| # | 項目 | 基準 | 対応ストーリー/AC |
|---|------|------|------------------|
| A1 | 文字サイズ | 本文・ラベル・ボタンが十分大きく読みやすい | NFR4 |
| A2 | コントラスト | 文字と背景のコントラストを確保（テキストは目安4.5:1以上を志向） | NFR4 |
| A3 | キーボード操作 | 「開く→カテゴリ選択→調整→保存」の主要動線をマウスなしで完了できる | ACX.1 |
| A4 | フォーカス可視 | 現在のフォーカス位置が視覚的に分かる | ACX.1 |
| A5 | モーダルのEsc | バッチ適用ダイアログをEscで閉じ、フォーカスが起動元に戻る | ACX.2 |
| A6 | ランドマーク構造 | header/nav/main/complementary/contentinfo の領域構造を持つ | [wireframes] |
| A7 | エラーメッセージ | エラーは日本語で理由が分かる文言（技術例外そのものを見せない） | FR1.3 |
| A8 | 操作ラベル | アイコンボタンにテキストラベルを併記する | NFR4 |

## mvpで対象外（将来検討）

- スクリーンリーダー完全対応の網羅検証。
- ハイコントラストテーマ／文字サイズのユーザー可変設定。
- 多言語対応（日本語UI固定）。

## Assumptions & Open Questions

- 具体的なコントラスト比・フォントサイズの数値は、スタック確定後のUI実装時に測定・調整する。
