# Refined Mockups — FF14 スクリーンショット加工ツール（mvp）

中忠実度のモックアップ。rough-mockups の骨格（左メニュー＋中央プレビュー＋右調整、リアルタイム反映、文字/ボタン大きめ、非破壊保存）を踏襲し、確定した詳細方針を反映する [wireframes][Q1][Q2][Q3][Q4]。

## 画面1: メイン編集画面

```
+===========================================================================+
| [📂 開く]  [💾 別名で保存]        FF14 SS 加工ツール        [🗂 バッチ適用] |  header / h1
+------------------+--------------------------------------+-----------------+
| 加工メニュー(nav) |            プレビュー(main)            | 調整(complementary)|
|                  |                                      |                 |
| ▸ 基本補正        |    +------------------------------+  |  ── 基本補正 ──  |
| ▸ 画質調整        |    |                              |  |  明るさ  [--●--] |
| ▸ フィルタ        |    |     加工結果を大きく表示       |  |  コントラスト[-●-]|
| ▸ トリミング      |    |     （操作で即時反映）         |  |  彩度    [--●--] |
| ▸ リサイズ        |    |                              |  |                 |
| ▸ クレジット      |    +------------------------------+  |  [ リセット ]    |
|                  |                                      |                 |
+------------------+--------------------------------------+-----------------+
| 元: screenshot001.png     出力先: 同フォルダ (_edited)     [ この1枚を保存 ] | contentinfo
+===========================================================================+
```
- 左メニューでカテゴリ選択 → 右パネルが該当カテゴリの操作に切替（AC1.1.3）。
- スライダー操作は中央プレビューに即時反映（リアルタイム）[US1.2][US1.3]。
- [リセット]で全調整を初期化しプレビューを未加工に戻す（US1.8）。
- 保存は非破壊（同フォルダに `_edited` 接尾辞、元と同形式）[US1.7]。
- a11y: h1=アプリ名、landmark=header/nav/main/complementary/contentinfo、キーボード起点=左メニュー、文字・ボタン大きめ [NFR4]。

## 画面2: クレジット設定（右パネル内の一状態）

```
|  ── クレジット ──            |
|  テキスト:                   |
|  [© SQUARE ENIX__________]  |  ← 既定テンプレート入り・編集可 [FR6.3]
|  位置: (●)右下 ( )左下 ( )中央下|
|  サイズ:   [--●--]           |
|  不透明度: [----●-]           |
```
- 既定文字列「© SQUARE ENIX」を初期表示、編集可能 [US1.6]。位置・サイズ・不透明度を指定。
- a11y: この状態は画面1の complementary(右調整)内。h3 見出し、キーボード操作可。

## 画面3: バッチ適用ダイアログ（modal）

```
+-------------------------------------------------------------+
|  同じ設定で複数枚に適用                               [×]    |  h2 / modal
|-------------------------------------------------------------|
|  適用する加工設定: 現在の編集内容を使用                       |
|  対象: (●) フォルダ [ 選択... ]   ( ) 複数ファイル [ 選択...] |
|  出力先: 同フォルダ (_edited)                               |
|  対象: 12 枚                                                |
|                                                             |
|  [進捗] ████████░░░░  12枚中 8枚処理中…                       |  ← 実行中に表示(AC2.1.4)
|                                                             |
|              [ キャンセル(閉じる) ]   [ 一括で適用して保存 ]  |
+-------------------------------------------------------------+
```
- 実行中は進捗を表示（AC2.1.4）。処理の途中キャンセルは提供しない（mvp）[Q3]。
- [キャンセル(閉じる)]は開始前にダイアログを閉じる操作。Escでも閉じる（ACX.2）。
- 完了後は「成功n件／失敗m件（n+m=総数）」を表示（AC2.1.3）。失敗はスキップ継続（AC2.1.2）。

## 画面状態一覧（各画面共通）

| 状態 | 見せ方 | Source |
|------|--------|--------|
| 空（画像未選択） | プレビュー領域に「画像を開いてください」の案内を表示 | [Q4] |
| 読み込み/処理中 | 進捗表示（バッチは件数、単体は即時反映のため通常は不要） | [Q4][AC2.1.4] |
| エラー | 日本語の分かりやすいメッセージ（例「このファイルは開けませんでした（対応形式は PNG / JPEG です）」）、アプリは継続 | [FR1.3][NFR1] |
| 成功 | 保存完了の簡潔な通知（保存先パスを表示） | [Q4] |

## Out of scope（mvp・詳細モックでの確定）

- 加工前後の比較機能（US1.9）はmvpに入れない [Q1]。
- プリセットのサムネイル一覧は採用しない（名前リストとする）[Q2]。
- バッチの途中キャンセルは採用しない [Q3]。
