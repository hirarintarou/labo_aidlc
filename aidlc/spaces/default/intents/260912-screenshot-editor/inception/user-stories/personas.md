# Personas — FF14 スクリーンショット加工ツール（mvp）

## P1. 制作者本人（プライマリ・唯一のペルソナ）

- **役割**: FF14プレイヤー兼、本ツールの開発者・利用者。自分で撮ったキャラクターのスクリーンショットを公開前に加工する [requirements][Q1]。
- **ゴール**:
  - 手作業では難しい品質の仕上がりを手軽に得たい [requirements]。
  - 多くの加工を試して、自分の感性に合う一枚を作りたい [requirements]。
  - 増えていく公開画像を、手作業に追われず処理したい [requirements]。
- **ペインポイント**:
  - 汎用の高機能な画像編集ソフトは用途に対して煩雑 [requirements]。
  - 1枚ずつ手で加工していると、公開枚数が増えると追いつかない [requirements]。
- **利用文脈**: Windows PC のローカル環境で、オフラインで作業する。個人利用で他者への配布は想定しない [requirements]。
- **優先度**: プライマリ（唯一のペルソナ）。

## Persona Relationships & Priority

- 本ツールは単一ペルソナ（P1）向け。閲覧者などの二次的な関係者はツール要件に影響しない（個人利用のため）[requirements]。
