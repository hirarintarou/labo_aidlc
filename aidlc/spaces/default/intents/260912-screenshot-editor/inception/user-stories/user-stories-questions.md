## Story Plan（方針のたたき台）

- **ペルソナ**: 制作者本人（FF14プレイヤーで、自分のスクショを公開前に加工したい人）1名。
- **フォーマット**: INVEST に沿い、「As a [ペルソナ], I want [目的], so that [便益]」＋受け入れ基準（Given/When/Then）。
- **分割方針（案）**: 機能領域ごと（読み込み／基本補正／画質調整／フィルタ／トリミング・リサイズ／クレジット／保存／単体編集／バッチ）。要件のFRグループに対応させる。
- **優先度**: 各ストーリーに MoSCoW（Must/Should/Could/Won't）を付与。
