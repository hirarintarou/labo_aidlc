# Team Allocation — FF14 スクリーンショット加工ツール（mvp）

**mob** ＝ 1つのBoltを担当する開発の担い手。本プロジェクトは個人開発（mvpスコープでチーム編成ステージはスキップ）のため、すべてのBoltを AI（aidlc-developer-agent）が担当し、あなたが都度承認する [Q3]。

## Bolt-to-mob Assignment

| Bolt | 担当 | 承認 |
|------|------|------|
| Bolt 1: 骨組み | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 2: 基本補正 | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 3: 画質調整 | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 4: フィルタ／プリセット | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 5: トリミング・リサイズ | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 6: クレジット付与 | aidlc-developer-agent（AI） | あなたが都度承認 |
| Bolt 7: バッチ処理 | aidlc-developer-agent（AI） | あなたが都度承認 |

## Ownership Model

- **体制**: solo（このセッションで1つずつ実装し、都度承認）[Q3]。
- 複数チーム分担（Program Board）は本件では不要（単一ユニット・個人開発）。
