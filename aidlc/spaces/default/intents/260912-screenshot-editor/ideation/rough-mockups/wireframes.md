# Wireframes — FF14 スクリーンショット加工ツール（mvp・低忠実度）

Windows専用デスクトップアプリ。中央プレビュー・左に加工メニュー・右に調整値、リアルタイム反映、文字/ボタン大きめ [Q1][Q2][Q5]。以下はレイアウトの当たりを示す低忠実度ワイヤーであり、色や細部は後続の refined-mockups で詰める。

## 画面1: メイン編集画面（単体プレビュー編集）

```
+---------------------------------------------------------------------------+
| [ファイルを開く] [別名で保存]        FF14 SS 加工ツール      [バッチ適用] |  ← ツールバー(上部)
+------------------+--------------------------------------+-----------------+
|  加工メニュー     |                                      |  調整パネル      |
|  (左)            |                                      |  (右)           |
|                  |                                      |                 |
| [ 基本補正 ]     |            プレビュー                  |  明るさ  [--o--] |
| [ 画質調整 ]     |        (加工結果を大きく表示)          |  コントラスト[-o-]|
| [ フィルタ ]     |                                      |  彩度    [--o--] |
| [ トリミング ]   |         ※操作すると即時反映            |  シャープ [-o---] |
| [ リサイズ ]     |                                      |                 |
| [ クレジット ]   |                                      |  [ リセット ]    |
|                  |                                      |                 |
+------------------+--------------------------------------+-----------------+
| 元: screenshot001.png    出力先: .../edited/            [ この1枚を保存 ] |  ← ステータスバー(下部)
+---------------------------------------------------------------------------+
```

- 左の加工メニューでカテゴリを選ぶと、右の調整パネルにそのスライダー/入力が出る。
- スライダー操作は中央プレビューに即時反映（リアルタイム）[Q2]。
- 「この1枚を保存」で非破壊保存（元は上書きせず出力先へ別名保存）[scope-document]。
- アクセシビリティ: h1=アプリ名（ツールバー）、landmark=header(ツールバー)/nav(左メニュー)/main(プレビュー)/complementary(右調整)/contentinfo(下部)。キーボード起点=左メニュー。文字・ボタンは大きめ [Q5]。

## 画面2: クレジット／ウォーターマーク設定（右パネル内の一状態）

```
+-----------------+
| クレジット       |
|-----------------|
| テキスト:        |
| [__________]    |
| 位置: (o)右下    |
|       ( )左下    |
|       ( )中央下  |
| サイズ: [--o--] |
| 不透明度:[---o-] |
| [ プレビュー反映 ] |
+-----------------+
```

- テキストを入力し、位置・サイズ（・不透明度）を選ぶだけの簡単な指定 [Q4]。
- 目的は公式ガイドライン遵守のクレジット付与 [scope-document]。

## 画面3: バッチ適用ダイアログ（「バッチ適用」から起動）

```
+-------------------------------------------------------------+
|  同じ設定で複数枚に適用                              [×]     |  ← h2
|-------------------------------------------------------------|
|  適用する加工設定: 現在の編集内容（画面1の設定）を使用       |
|                                                             |
|  対象の選び方:                                              |
|   (o) フォルダを選ぶ   [ フォルダ選択... ]  未選択          |
|   ( ) 複数ファイルを選ぶ [ ファイル選択... ]                |
|                                                             |
|  出力先フォルダ: [ 選択... ]  .../edited/                   |
|  対象: 12 枚                                                |
|                                                             |
|                       [ キャンセル ]   [ 一括で適用して保存 ]|
+-------------------------------------------------------------+
```

- 画面1で加工を決めた後に開き、「同じ設定」をフォルダ／複数ファイルへ一括適用 [Q3]。
- すべて非破壊（出力先へ別名保存）[scope-document]。
- アクセシビリティ: モーダルはh2見出し、キーボードで全操作可、Escで閉じる [Q5]。
