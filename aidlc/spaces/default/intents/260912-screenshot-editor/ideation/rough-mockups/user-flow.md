# User Flow — FF14 スクリーンショット加工ツール（mvp）

利用者は制作者本人。中心的な流れは「1枚を開いて加工 → 保存」、および「その設定を複数枚へ一括適用」[intent-statement][Q3]。

## Happy Path: 単体編集フロー

```mermaid
flowchart TD
    A[アプリ起動] --> B[ファイルを開く<br/>PNG/JPEG]
    B --> C[中央にプレビュー表示]
    C --> D[左メニューで加工カテゴリ選択<br/>基本補正/画質/フィルタ/トリミング/リサイズ/クレジット]
    D --> E[右パネルで値を調整<br/>プレビューに即時反映]
    E --> F{仕上がりに満足?}
    F -- いいえ --> D
    F -- はい --> G[この1枚を保存<br/>元は上書きせず別名保存]
    G --> H{他の画像も加工する?}
    H -- 同じ設定で複数枚 --> I[バッチ適用フローへ]
    H -- 別の1枚を編集 --> B
    H -- 終了 --> Z[完了]
```

テキストフォールバック（単体編集）: 起動 → 画像を開く → プレビュー表示 → 左メニューで加工を選ぶ → 右で調整（即時反映）→ 満足するまで繰り返し → 別名保存 → 続けて別画像/バッチ/終了を選ぶ。

## Happy Path: バッチ適用フロー

```mermaid
flowchart TD
    A[画面1で加工設定を決定] --> B[「バッチ適用」を開く]
    B --> C[対象を選ぶ<br/>フォルダ or 複数ファイル]
    C --> D[出力先フォルダを選ぶ]
    D --> E[一括で適用して保存]
    E --> F[各画像に同じ設定を適用<br/>すべて非破壊で別名保存]
    F --> G[完了件数を表示]
    G --> Z[完了]
```

テキストフォールバック（バッチ）: 画面1で加工を決める → 「バッチ適用」を開く → フォルダ/複数ファイルを選ぶ → 出力先を選ぶ → 一括適用して保存 → 全件を非破壊保存 → 完了件数表示。

## Information Architecture（情報の階層）

```
アプリ
├─ ツールバー（開く / 保存 / バッチ適用）
├─ 加工メニュー（左）
│   ├─ 基本補正（明るさ・コントラスト・彩度）
│   ├─ 画質調整（シャープ・ぼかし・ノイズ除去）
│   ├─ フィルタ／プリセット
│   ├─ トリミング
│   ├─ リサイズ
│   └─ クレジット／ウォーターマーク
├─ プレビュー（中央・即時反映）
├─ 調整パネル（右・選択カテゴリの値）
└─ ステータスバー（元ファイル / 出力先 / 保存）
```
